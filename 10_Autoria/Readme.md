# Auditoría, autoría y trazabilidad — SICST

Esta carpeta reúne las evidencias de autoría, sesiones de trabajo, aportes
individuales, notas de campo, archivos fuente, integridad de archivos y doble
codificación del proyecto **Sistema Inteligente de Control y Seguimiento de
Terapia Física (SICST)**.

**Repositorio vigente:** <https://github.com/gleiston-guerrero/SICST_ISR401>

## Criterios de integridad

- Los nombres se normalizan mediante `.mailmap` sin modificar commits.
- Las notas reconstruidas se identifican como retrospectivas.
- La falta de una firma, fecha o respaldo se declara; no se completa por
  aproximación.
- Los archivos multimedia se verifican mediante tamaño y SHA-256 aunque no
  contengan metadatos EXIF.
- Los cambios posteriores al cierre requieren regenerar inventarios y
  checksums antes de crear la etiqueta final.
